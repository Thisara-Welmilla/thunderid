# Account Recovery

In this walkthrough, John has forgotten his Wayfinder password. He selects **Forgot password?** on the sign-in screen,
receives a recovery email, opens the link, and sets a new password. <ProductName /> runs the recovery flow end-to-end
and returns him to Wayfinder ready to sign in with the new credentials.

:::note Prerequisites
Complete [Set Up Your Environment](../../build-environment) before starting this walkthrough.
:::

:::info Background
[Understand It](../../overview) covers the requirements story behind this use case.
:::

## Set Up Account Recovery

1. Recovery emails are delivered through a SMTP server. Configure a SMTP provider and apply the configuration in
   `deployment.yaml`.

   **Sample SMTP Configuration:**

   ```yaml
   email:
     smtp:
       host: '<smtp-host>'
       port: <smtp-port>
       username: '<smtp-username>'
       password: '<smtp-password>'
       from_address: '<from-address>'
       enable_start_tls: true
       enable_authentication: true
   ```

2. Restart <ProductName /> for the changes to take effect.

## About the Recovery Email

The email John receives is produced from a **notification template**, not fixed text baked into the recovery flow. The
template holds the subject and message content; its appearance follows the application's theme from Design & Branding;
and its text can be translated so each customer is emailed in their own language. <ProductName /> composes the three at
send time: it resolves the content for the recipient's locale, wraps it in the application's branding, and substitutes
runtime values such as the application name and the recovery link.

In the configured sample you can inspect all three without changing anything:

- Open **Notification Templates** in the Console, stay on the **Email** channel, and select **Edit** on the
  **Password Recovery** template. The editor shows the subject and body as plain content, and the **Preview** panel
  renders the message **as delivered**, wrapped in the sample's branding.
- Switch the **LANGUAGE** selector in the editor, or the language in the preview, to see the same email in another
  translated language.
- Compare the preview with the recovery email John received in the walkthrough above; it is the same message.

To customize any of this yourself, see [Customize the Recovery Email](../../build-recovery-email) in the Build It
tutorial.
